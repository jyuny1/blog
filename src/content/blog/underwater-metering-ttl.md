# 前言
在剛開始學習水下攝影時，總是會看陸上攝影的一些相關影片。幾乎每個單眼相機都會有測光模式相關的影片。所以自然而然在水下攝影的時候就會帶入陸上攝影的測光模式概念。但在這幾年的實踐中發現，其實相機測光模式在完全手動模式下水下攝影中的影響程度並沒有像陸上攝影一樣大。
# 什麼是測光模式
根據 [Nikon Z8 的測光說明](https://onlinemanual.nikonimglib.com/z8/zh-tw/psm_metering_141.html)：測光決定了相機設定曝光的方式。

| 選項     | 說明                                                                                                                                                                                                    |
| ------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 矩陣測光   | 相機對畫面的廣泛區域進行測光，並根據色調分佈、色彩、構圖及距離設定曝光以獲取接近肉眼所見的效果。                                                                                                                                                      |
| 偏重中央測光 | - 相機將最大比重指定給畫面的中央區域。例如，此模式可用於佔據大部分構圖的主體。<br>- 當使用曝光系數（濾光系數）大於 1 倍的濾鏡時也建議使用偏重中央測光。<br>- 使用用戶設定 b5 [**偏重中央區域**] 可選擇被指定最大比重的區域的大小。<br>- 可以使用用戶設定 d19 [**自定螢幕拍攝顯示**] 和 d20 [**自定觀景器拍攝顯示**] 顯示或隱藏測光區域。     |
| 重點測光   | - 相機對 4 mm 直徑圈（相當於畫面的約 1.5%）進行測光。這樣可確保即使背景很亮或很暗時也能對主體進行正確的曝光。<br>- 測光區域以目前對焦點為中心。若將 AF 區域模式選為 [**自動區域 AF**](https://onlinemanual.nikonimglib.com/z8/zh-tw/focus_31.html#af-area_mode)），相機將對中央對焦點進行測光。 |
| 高光偏重測光 | 相機將最大比重分配給高光區域。使用該選項可減少高光細節遺失，例如拍攝舞台上聚光燈下的演員。                                                                                                                                                         |

**需要注意的是，Nikon 說明書主要說明相機本身怎麼測光、怎麼控制曝光。水下拍攝加上外接閃光燈後，還要看閃光燈是手動輸出還是 TTL。**

# 全手動且設定固定時，測光模式不影響相機進光量
如果相機使用 M mode、ISO 固定（關閉自動 ISO），同時閃光出力也是手動控制，那測光模式對相機進光量沒有作用。

1. 快門與光圈：由攝影者手動設定，不受測光模式影響
2. ISO：固定 ISO 時由攝影者設定。如果 M 模式開了自動 ISO，相機仍會依測光結果調整 ISO
3. 閃光燈出力：手動模式下由攝影者設定，不受測光模式影響

但測光模式仍影響相機界面中的曝光指示(但不影響實際成像，可忽略)，例如下圖的 22 曝光指示器

# 什麼時候測光模式會影響曝光
**在水下使用 TTL 拍攝時**，測光結果會影響 TTL 的計算進而影響閃燈出力。同時開啟自動 ISO 或使用 P、S、A 模式時，曝光也會受測光模式影響。

## TTL 的計算流程
1. **預閃**：相機會透過閃光燈發出低功率的測試脈衝
2. **測光**：相機的 TTL 測光表透過鏡頭測量從場景反射的光線
3. **計算**：相機決定正確的閃光持續時間／出力
4. **閃光執行**：閃光燈依照計算出的出力值發光
5. **閃光熄滅（Quench）**：絕緣閘雙極電晶體（Insulated Gate Bipolar Transistor）會在正確的時機截斷閃光燈管

**其中 4-5 閃光執行與熄滅的時間稱作閃光持續時間（flash duration time），是閃光燈凝結動態的重要參數，越短的閃光持續時間，能夠凝結越快的動作並提供更乾淨沒有殘像的畫面**

# 水下拍攝應該使用手動操作或 TTL
陸上 TTL 使用已經非常成熟，而且已經作為日常拍攝的工作流程之一。但水下攝影中手動調整曝光或使用 TTL 一直有不同意見。

目前 TTL 在水下仍然有非常多的挑戰。原因是當前相機 TTL 測光主要為陸上拍攝設計，直接用在水下會因爲水下環境變動成像品質不一致。根據我的經驗，主體占滿畫面時 TTL 的結果相對穩定，但背景是大片藍水時就會容易有過曝或欠曝的結果。

我使用 [UWT 11032-HSS](https://uwtechnics.com/product/11032-hss-ttl-converter-for-nikon-for-nauticam-underwater-housings/) 的經驗：
1. 黑水攝影：搭配 TTL + 偏重中央測光能獲得不錯的效果
2. 廣角攝影：我個人會使用閃光燈手動出力
3. 微距攝影：
	1. 雙燈+對焦燈搭配中焦段拍攝中小型生物，我個人會使用閃光燈手動出力
	2. 拍攝生物行為如麒麟魚交配（還需要紅色對焦燈）這種瞬間決定曝光，我會嘗試使用 TTL
	3. snoot 我個人會使用閃光燈手動出力

## TTL 不適合的情況
- 需要刻意過曝拍攝的生物，例如黑色娃娃魚
- 結構相對複雜的環境或生物，例如身上有毛的娃娃魚或章魚，或躲在貝殼內中的小魚
- 需要特殊打光角度展現生物身上的皮膚質感時
